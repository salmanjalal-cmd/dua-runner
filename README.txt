DUA RUNNER GAME

Play the game online: https://salmanjalal-cmd.github.io/dua-runner/

PLAY
Enter the player's name. The child runs through eight scenes, jumps over barriers, collects stars, and answers a dua question at each checkpoint. Tap the screen or Jump button, or press Space / Up Arrow on a computer. A wrong answer stays at the question; the correct answer unlocks the next scene.

ADD TO YOUR PHONE
Android: Open the link in Chrome, tap the three-dot menu, then Install app or Add to Home screen.
iPhone: Open the link in Safari, tap Share, then Add to Home Screen.
Share the same link with anyone. Internet is needed for online narration and dua audio.

The game has no account or backend. It is hosted on GitHub Pages. The source files are in this repository.
