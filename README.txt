DUA RUNNER GAME

PLAY ON A PHONE OR COMPUTER
Enter the player's name. The child runs through eight scenes. Tap the game screen or Jump button, or press Space / Up Arrow on a computer, to jump over barriers and collect stars. At each dua checkpoint, the Urdu narrator asks a question using the player's name. A wrong answer stays at that question. The correct answer plays a human Arabic recitation and unlocks the next run.

INSTALL ON ANDROID
1. The game folder must first be uploaded to an HTTPS static website. Opening index.html from the ZIP on a phone does not install the app.
2. Open the website link in Chrome.
3. Tap the three-dot menu, then Install app or Add to Home screen.
4. The Dua Runner icon will open the game like an app. Share that same website link with other people.

INSTALL ON IPHONE
1. Open the game's HTTPS website link in Safari.
2. Tap Share, then Add to Home Screen.
3. Tap Add. The icon will open the game in a full-screen app window.

The game files are ready for upload, but this folder has not been published as an internet link yet. You need an HTTPS static host to share it with people. The game itself has no account or backend.

VOICE AND INTERNET
The game uses an Urdu speech voice installed on the device when available. If none is installed, it tries an online Urdu narrator. Online narration and Arabic dua recordings need internet. If the browser blocks automatic sound, tap Replay. Arabic dua recordings are human recitations, not generated speech. OpenDua audio is streamed from their service; Qur'an verses use EveryAyah recordings by Mishary Alafasy. Sources are shown with each answer.
